# OpenMind Core: reference results

Reproducible reference results of the decoding pipeline, measured on public
data before any recording with the OpenMind headset. Every table below is
copied from a file of `research/results/` generated by a script and a
configuration of this repository; section [Reproduce](#reproduce) gives the
commands. Accuracies are in %, mean ± standard deviation over subjects, chance
is 33 % for three classes and 50 % for two.

*Research and experimentation project — not a medical device.*

## Summary

| Question | Answer on public data | Source |
|---|---|---|
| Which electrodes? | Montage C, the seven motor electrodes of montage A plus **CPz**: the best eighth electrode (+1.4 to +2.2 points over seven). | [montage](results/montage.md) |
| How good is a model for a user it has never seen? | 52–55 % on three classes without alignment. | [montage C](results/montage-c.md) |
| What does alignment bring with **no labelled trial**? | **+6 to +11 points** (ts-lr 53.4 → 59.2 %, mdm 42.8 → 53.7 %), from unlabelled signal only. | [calibration curve](results/calibration-curve.md) |
| How many trials does calibration need? | Fine-tuning the aligned model keeps improving up to 40 trials per class (ts-lr 67.2 %); it matches a personal model trained from scratch from 10 trials per class and beats it below. | [calibration curve](results/calibration-curve.md) |
| Does picking similar users help? | No: the 3 nearest profiles give 56–60 %, the same as the aligned generic model (55.6–61.6 %). | [cold start](results/calibration-curve-coldstart.md) |
| Deep learning? | EEGNet is not better than the Riemannian baselines on 8 electrodes; fine-tuned on the user's trials it matches tuned ts-lr (67.7 vs 67.2 % at 40 trials per class). | [deep](results/deep.md), [deep calibration](results/calibration-curve-deep.md) |
| Foundation model? | No gain: fine-tuned LaBraM reaches 59.1 % at 40 trials per class, 8 points below ts-lr, for far more computation. | [foundation](results/calibration-curve-foundation.md) |
| Which gesture for `action`? | A **double jaw clench**, read on the motor electrodes: 68 % of the clenches detected, 0.6 false double clench per hour. | [jaw](results/jaw-run2.md) |
| Is the loop fast enough? | Decoder latency 2.9 ms on average (p95 4.9 ms) on a laptop CPU. | Sandbox `docs/full-chain.md` |

## Setup

* **Data.** BCI Competition IV 2a (`bnci2014_001`: 9 subjects, 2 sessions,
  22 electrodes at 250 Hz) for the main results; PhysioNet EEGMMIDB
  (`physionetmi`, 160 Hz, one session) as a second dataset; PhysioMotion
  Artifact (OpenNeuro ds006386, CC0) for the jaw clench. All are downloaded by
  MOABB or the scripts into `$OPENMIND_DATA_DIR`, never committed.
* **Classes.** `left` (left hand), `right` (right hand), `forward` (feet), as
  the OpenMind commands; two-class tables use left and right only.
* **Preprocessing.** The online pipeline offline: montage C
  (`FC3, FC4, C3, Cz, C4, CP3, CP4, CPz`), causal 8–30 Hz band-pass and mains
  notch, resampling to 250 Hz, epochs `[cue + 0.5 s, cue + 2.5 s]`, rejection
  above 150 µV peak to peak. See [`docs/pipeline.md`](../docs/pipeline.md).
* **Models.** CSP + LDA, MDM and tangent space + logistic regression (`ts-lr`)
  with pyRiemann; EEGNet and ShallowConvNet with braindecode; LaBraM from its
  public pre-trained weights (Hugging Face `braindecode/labram-pretrained`).
* **Protocols.** Within-session (5-fold), cross-session (train on one session,
  test on the other), cross-subject (leave one subject out). For the
  calibration curve, the first trials of each session of the left-out subject
  are its calibration set and the following ones the common test set
  ([`docs/evaluation.md`](../docs/evaluation.md)).
* **Hardware.** One laptop CPU (Apple silicon, no GPU). Seeds are fixed
  (42 unless stated); deep results vary with the seed and are averaged over
  several seeds where stated.

## 1. Baselines and deep models

Three classes, montage C, BCI IV 2a:

| Model | within-session | cross-session | cross-subject |
|---|---|---|---|
| `csp-lda` | 70.2 ± 16.7 | 67.8 ± 15.9 | 53.5 ± 17.1 |
| `ts-lr` | 69.2 ± 16.1 | 65.6 ± 14.8 | 54.8 ± 18.5 |
| `eegnet` | 56.4 ± 22.6 | 58.5 ± 23.1 | 55.0 ± 16.8 |
| `shallow` | 61.3 ± 16.0 | 61.8 ± 16.1 | 50.3 ± 15.6 |

With one subject's data (within- and cross-session), the Riemannian baselines
beat the networks by 6 to 14 points: about 250 trials are too few to train a
network. Across subjects, every model falls to 50–55 %: the problem a new user
faces. On two classes, cross-subject ts-lr and EEGNet reach 71–72 %. Full
tables, PhysioNet and montage A: [montage-c.md](results/montage-c.md),
[baselines.md](results/baselines.md), [deep.md](results/deep.md).

## 2. Alignment

Re-centering each session on its own reference covariance (Euclidean or
Riemannian alignment) removes most of the shift between sessions and users:

| Model | cross-subject, none | Euclidean | Riemannian | Riemannian, first 20 trials |
|---|---|---|---|---|
| `csp-lda` | 53.5 | 61.2 | 61.9 | 60.2 |
| `mdm` | 42.9 | 59.9 | 59.8 | 57.7 |
| `ts-lr` | 54.8 | 63.1 | 61.9 | 59.9 |
| `eegnet` | 55.0 | 61.2 | 60.8 | 60.2 |

The last column estimates the reference from the first 20 trials of the session
only, as the online decoder does with its warm-up: most of the gain remains.
Source: [alignment.md](results/alignment.md).

## 3. Montage

Adding one electrode to the seven motor electrodes of montage A, within-session
on BCI IV 2a (three classes): CPz is the best eighth electrode (+1.9 points
with csp-lda, +1.4 with ts-lr, forward recall +1.8 / +2.8), ahead of FCz, C1
and C2. Blinks cannot be detected reliably without Fp1, and a double blink is a
poor command (false positives during reading). Montage C is therefore the
eight motor electrodes, without Fp1. Sources: [montage.md](results/montage.md),
[`docs/montage.md`](../docs/montage.md).

## 4. Calibration curve (main result)

Accuracy on the common test set of each new user, BCI IV 2a, three classes,
montage C, as a function of the number of calibration trials per class:

| `ts-lr` | 0 | 5 | 10 | 20 | 40 |
|---|---|---|---|---|---|
| `generic` (other subjects, no alignment) | 53.4 | 53.4 | 53.4 | 53.4 | 53.4 |
| `aligned` (reference from unlabelled trials) | 59.2 | 59.1 | 59.0 | 59.9 | 59.8 |
| `aligned+tuned` (calibration trials added, weight 10) | 59.2 | 59.8 | 60.8 | 62.9 | **67.2** |
| `scratch` (user's trials only) | — | 53.8 | 60.2 | 62.5 | 66.7 |

| `mdm` | 0 | 5 | 10 | 20 | 40 |
|---|---|---|---|---|---|
| `generic` | 42.8 | 42.8 | 42.8 | 42.8 | 42.8 |
| `aligned` | 53.7 | 53.9 | 56.2 | 57.1 | 57.2 |
| `aligned+tuned` | 53.7 | 54.7 | 58.0 | 59.1 | 61.3 |
| `scratch` | — | 54.2 | 58.9 | 60.1 | 62.8 |

| `csp-lda` | 0 | 5 | 10 | 20 | 40 |
|---|---|---|---|---|---|
| `generic` | 52.1 | 52.1 | 52.1 | 52.1 | 52.1 |
| `aligned` | 59.0 | 58.5 | 59.2 | 59.8 | 59.9 |
| `aligned+tuned` | 59.0 | 60.1 | 62.4 | 62.7 | 65.2 |
| `scratch` | — | 55.7 | 61.2 | 63.4 | 66.2 |

Standard deviations are 8 to 18 points (subjects differ a lot); they are in
the source file with Cohen's κ.

* **Zero trials.** Alignment alone gives +6 to +11 points for free: the
  decoder needs only 20 trials, or 30 s of rest, of unlabelled signal. On
  PhysioNet (54 subjects, one session, 60 Hz), the same gain is +5 to +10
  points (ts-lr 44.9 → 51.7 %, mdm 39.1 → 48.9 %).
* **Few trials.** With 5 trials per class, training from scratch is no better
  than the generic model (53.8 %), while the tuned aligned model never falls
  below its zero-trial accuracy. From 10 trials per class, both reach about
  the same accuracy, and at 40 per class (120 cued trials, about a quarter of an hour),
  tuned ts-lr reaches 67.2 %.
* **Consequence for OpenMind.** A new user starts with the aligned generic
  model after the warm-up, and the personal model takes over progressively
  during calibration (`status.assistance`, [`docs/calibration.md`](../docs/calibration.md)).

Source: [calibration-curve.md](results/calibration-curve.md).

## 5. Similarity-based cold start

Instead of all source subjects, start from the 3 source subjects whose resting
covariances are nearest to the new user's (Riemannian distance), at zero
trials:

| Model | `aligned` (all sources) | `coldstart-knn` (3 nearest) |
|---|---|---|
| `ts-lr` | 61.6 ± 13.7 | 58.9 ± 14.9 |
| `mdm` | 55.6 ± 8.0 | 56.2 ± 11.6 |
| `csp-lda` | 61.3 ± 15.3 | 59.8 ± 12.8 |

With 8 source subjects, choosing neighbours does not help: once aligned, more
training data matters more than similarity. The question should be asked
again with a larger pool of profiles (Lee2019 or Cho2017, 50+ subjects).
Source: [calibration-curve-coldstart.md](results/calibration-curve-coldstart.md).

## 6. Fine-tuning EEGNet

EEGNet pre-trained on the aligned source subjects, then fine-tuned on the
calibration trials of the new user, with four strategies: the classification
layer only (`head`), the last block (`final`), a linear spatial adapter in
front of the frozen network (`adapter`), or every weight (`full`). Same
protocol and test set as section 4, averaged over 3 seeds:

| `eegnet` | 0 | 5 | 10 | 20 | 40 |
|---|---|---|---|---|---|
| `aligned` | 57.7 | 57.8 | 58.0 | 57.5 | 57.8 |
| `aligned+finetune-head` | 57.7 | 60.5 | 61.9 | 64.7 | 66.8 |
| `aligned+finetune-final` | 57.7 | 59.7 | 61.3 | 63.8 | 66.3 |
| `aligned+finetune-adapter` | 57.7 | 58.4 | 59.1 | 60.3 | 63.2 |
| `aligned+finetune-full` | 57.7 | 60.5 | 61.6 | 64.6 | **67.7** |
| `ts-lr` `aligned+tuned` (section 4) | 59.2 | 59.8 | 60.8 | 62.9 | 67.2 |

* Every strategy improves with the number of trials; fine-tuning the head or
  the whole network is the best, the spatial adapter the weakest (an 8 × 8
  layer has too many parameters for 5 trials per class).
* Fine-tuned EEGNet is 1 to 2 points above tuned ts-lr from 5 to 20 trials per
  class and equal at 40: differences within the spread between subjects
  (13–15 points). The Riemannian model stays the default: it trains in
  seconds on a CPU, where the deep curve took about an hour.

Source: [calibration-curve-deep.md](results/calibration-curve-deep.md).

## 7. Foundation model (LaBraM)

LaBraM, pre-trained on about 2,500 hours of EEG, from its public weights,
trained on the aligned source subjects then fine-tuned on the user's trials
(head only or whole network), averaged over 2 seeds:

| `labram` | 0 | 5 | 10 | 20 | 40 |
|---|---|---|---|---|---|
| `generic` (no alignment) | 38.5 | 38.5 | 38.5 | 38.5 | 38.5 |
| `aligned` | 52.0 | 52.3 | 52.0 | 51.9 | 52.3 |
| `aligned+finetune-head` | 52.0 | 51.3 | 53.5 | 55.0 | 56.3 |
| `aligned+finetune-full` | 52.0 | 51.6 | 53.7 | 57.1 | 59.1 |

LaBraM stays 6 to 9 points below ts-lr and EEGNet at every point of the
curve. Alignment matters even more for it (+13.5 points), and fine-tuning
helps from 10 trials per class, but large-scale pre-training does not make
up for 8 electrodes and 2 s windows, far from the many-channel recordings it
was pre-trained on. It is not used in OpenMind; the question can be asked
again with more electrodes or other foundation models
([`research/notes/foundation-models.md`](notes/foundation-models.md)).

Source: [calibration-curve-foundation.md](results/calibration-curve-foundation.md).

## 8. The `action` gesture

Jaw clench, PhysioMotion Artifact run 2 (30 subjects, 57 blocks of 5 cued
clenches, 581 min):

| Detector | Clenches detected | False / min | False double clenches / hour |
|---|---|---|---|
| openmind-core defaults (peak ≥ 20 dB for ≤ 1 s, 7 motor electrodes) | 68 % | 0.28 | 0.6 |
| same rule, Fp1 alone | 53 % | 0.28 | 1.2 |

A single clench is too frequent by accident (0.3 per minute); requiring two
within a short interval brings false `action` commands below one per hour.
The motor electrodes detect clenches better than Fp1. To be checked on the
dry electrodes of the IronBCI-8. Sources: [jaw-run2.md](results/jaw-run2.md),
[`docs/action-gesture.md`](../docs/action-gesture.md).

## 9. Real-time loop

The full chain (synthetic EEG → `openmind-core online` → MQTT → fake robot and
Godot) runs on one laptop. Decoder latency, from the last EEG sample of a
window to the publication of the command: mean 2.9 ms, p50 2.3 ms, p95 4.9 ms,
max 15.8 ms (66 commands). The perceived delay is dominated by the 2 s window
and the 1 s evidence averaging, not by computation.

## Limits

* All results come from **gel electrodes in laboratory conditions**. The
  IronBCI-8 has dry electrodes: lower signal-to-noise ratio, and the numbers
  will drop. Phase B measures them with the headset.
* Motor imagery datasets are small (9 subjects for BCI IV 2a); standard
  deviations are large and differences of 1–2 points are not significant.
* Offline accuracy is not online control: the user also learns with feedback,
  which these results do not capture.
* Three classes with feet imagery as `forward`; `rest` is not a trained class
  but the decision when no command has enough evidence ([`docs/pipeline.md`](../docs/pipeline.md)).

## Reproduce

```bash
uv sync --extra research --extra deep        # add --extra foundation for LaBraM
export OPENMIND_DATA_DIR=~/openmind-data

uv run python research/experiments/benchmark.py --config research/configs/baselines.yaml
uv run python research/experiments/benchmark.py --config research/configs/deep.yaml
uv run python research/experiments/benchmark.py --config research/configs/montage-c.yaml
uv run python research/experiments/benchmark.py --config research/configs/alignment.yaml
uv run python research/experiments/montage.py
uv run python research/experiments/jaw.py --run 2
uv run python research/experiments/calibration_curve.py --config research/configs/calibration-curve.yaml
uv run python research/experiments/calibration_curve.py --config research/configs/calibration-curve-coldstart.yaml
uv run python research/experiments/calibration_curve.py --config research/configs/calibration-curve-deep.yaml
uv run python research/experiments/calibration_curve.py --config research/configs/calibration-curve-foundation.yaml
```

Each script rewrites its file in `research/results/` (with the date, the
commit and the package versions) and logs the runs to MLflow in
`$OPENMIND_DATA_DIR`. Long runs keep per-subject checkpoints in
`$OPENMIND_DATA_DIR/cache/` and resume after an interruption; on a laptop,
prevent sleep (`caffeinate -i` on macOS). Run times on one laptop CPU: a few
minutes for the baselines and the Riemannian calibration curve, about an hour
for EEGNet fine-tuning, about half an hour for LaBraM.
